## Что такое Git
Git — система контроля версий. Она запоминает изменения в файлах,
позволяет возвращаться к прошлым версиям и работать над проектом вместе с другими.

## Основные понятия

- **Репозиторий (repo)** — папка проекта, за изменениями которой следит Git.
- **Коммит (commit)** — «снимок» состояния файлов в определённый момент.
- **Ветка (branch)** — отдельная линия разработки.
- **Удалённый репозиторий (remote)** — копия проекта на сервере (например, GitHub).
- **HEAD** — указатель на текущий коммит/ветку.
- **Staging area (индекс)** — область, куда складываются изменения перед коммитом.

## Настройка (один раз)

```bash
git config --global user.name "Имя"
git config --global user.email "email@example.com"

----------------------------------------------------

git init                 # создать новый репозиторий в текущей папке
git clone <url>          # скопировать удалённый репозиторий локально

git status               # что изменилось
git add <файл>           # добавить файл в индекс
git add .                # добавить все изменения
git commit -m "Сообщение"  # зафиксировать изменения
git log                  # история коммитов
git log --oneline        # история кратко

git remote add origin <url>   # привязать удалённый репозиторий
git remote -v                 # список удалённых репозиториев
git push -u origin main       # отправить изменения на GitHub (первый раз)
git push                      # отправить изменения
git pull                      # забрать изменения с сервера
git fetch                     # получить изменения, не сливая их

git branch                    # список веток
git branch <имя>              # создать ветку
git checkout <имя>            # переключиться на ветку
git checkout -b <имя>         # создать и сразу переключиться
git merge <имя>               # слить ветку в текущую
git branch -d <имя>           # удалить ветку

git restore <файл>            # отменить изменения в файле (не в индексе)
git restore --staged <файл>   # убрать файл из индекса
git reset --soft HEAD~1       # отменить последний коммит, оставив изменения
git reset --hard HEAD~1       # отменить последний коммит и изменения (осторожно!)
